# PLO Plataforma

Monorepositorio de los prototipos digitales de PLO Droguería.

## Módulos

- `apps/PLOLanding`: sitio público y captación de clientes.
- `apps/Portal-PLO`: portal B2B, catálogo, carrito y pedidos.
- `apps/Admin-PLO`: panel administrativo y atención al cliente.
- `apps/CentralFacturacionPLO`: pagos, facturación y despacho.
- `apps/Portalwhatsapp`: puesto de atención estilo WhatsApp.
- `apps/Sistema-de-compras-PLO`: asistente de compras informadas.

## Estado actual

Los módulos son prototipos autocontenidos en HTML, CSS y JavaScript. Utilizan datos simulados y todavía no comparten autenticación, persistencia ni backend.

Los seis repositorios originales se mantienen intactos. Este repositorio será el punto de trabajo unificado para las siguientes modificaciones.

## Próxima etapa

1. Unificar navegación, identidad visual y componentes compartidos.
2. Definir el modelo común de clientes, productos, inventario, pedidos y pagos.
3. Reemplazar los datos simulados por servicios persistentes.
4. Integrar autenticación, pagos, WhatsApp, facturación y el asistente de compras.
