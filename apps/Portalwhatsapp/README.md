# Admin-PLO

Panel de Atención al Cliente — PLO Droguería Portal B2B.

Prototipo funcional con datos simulados para el equipo de telemarketing: centro de conversaciones estilo WhatsApp (con contexto de carrito en vivo por cliente), listas de difusión segmentadas por nivel, y KPIs de conversaciones activas, mensajes sin responder y casos resueltos.

No está conectado a la API real de WhatsApp Business todavía — eso requiere backend (webhook + verificación de negocio en Meta), planificado como fase siguiente.

Publicado en GitHub Pages: https://retiniasur-hash.github.io/Portalwhatsapp/
